mote Native AOT release dependency notices
=========================================

mote itself is licensed under GPL-3.0; the complete license is in LICENSE.
The release includes a source archive of the exact sourceCommit recorded in
package-manifest.json. Build and packaging instructions are in that source.

The Mote.Native project references the following production libraries through
Mote.Formats and Mote.Configuration. The net10.0 dependency groups have no
additional NuGet runtime dependencies. Analyzer/build-time code is not shipped
as a runtime plugin. The Desktop/Avalonia prototype is not this release product;
Avalonia, Skia, HarfBuzz and ANGLE are not bundled by this native release path.

.NET Native AOT runtime — MIT and third-party notices
Source: https://github.com/dotnet/runtime/tree/v10.0.11
Release workflow pins SDK 10.0.400 (runtime 10.0.11); the actual SDK version
is also recorded in every package manifest. A SDK/runtime upgrade requires
updating these notices from the matching runtime source, not silently using
the old notice inventory for a new runtime.
Full original license: packaging/licenses/dotnet-runtime.txt
Upstream runtime notice inventory: packaging/licenses/dotnet-runtime-notices.txt
The upstream inventory is intentionally conservative: it does not assert that
every listed optional .NET component is linked into mote's native executable.

Windows system RichEdit/User32 and macOS system AppKit/CoreText are provided by
the operating system, not redistributed as application payloads. No operating
system DLLs, user fonts or input-method data are copied into this release.

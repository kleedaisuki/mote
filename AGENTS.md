# Repository agent instructions

- Continue goal work until the assigned task is actually complete. A request for progress means report once and continue; do not stop solely to report.
- Do not repeat completed work or re-run completed validation unless a failure points back to it.
- After context compaction, preserve the current pace and do not recreate completed reports.
- Report at meaningful milestones or when a material blocker appears.
- Persist reusable findings promptly in the repository; do not leave valuable knowledge in transient exploratory messages.
- Keep project experiments and test artifacts inside the repository, under root `.cache/` or `.temp/`; do not create them elsewhere.
- Assign file areas with one writer per area rather than imposing a repository-wide edit lock. Coordinate public API changes before integration.
